# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately to the project maintainers.

Please include:
- A description of the issue
- Steps to reproduce the vulnerability
- The potential impact
- Any suggested fixes

## Response Process

We aim to:
- Acknowledge reports promptly.
- Investigate all valid reports.
- Release fixes as soon as possible.
- Keep reporters informed throughout the process.

## Supported Versions

Currently, only the latest version of the project is actively supported.
